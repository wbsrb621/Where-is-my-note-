위젯

바탕화면 위젯 표시 방식
위젯 표시 바탕화면 위젯을 사용합니다.
위젯 항상 위 다른 창 위에 위젯을 고정합니다.
메모 크기 위젯에 표시되는 메모의 높이를 조절합니다.
위젯 디스플레이 위젯을 표시할 모니터를 선택합니다.
위젯 위치 화면 가장자리에서 위젯이 나타나는 방향입니다.

데이터

메모와 설정 데이터를 저장하거나 불러옵니다.
데이터 저장 현재 모든 메모, 그룹, 설정을 세이브파일로 내보냅니다.
데이터 불러오기 저장해둔 세이브파일을 불러와 현재 데이터를 교체합니다.
